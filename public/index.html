Como funciona
1. Cliente clica no anúncio → abre WhatsApp com mensagem pré-pronta
2. Mensagem chega no Orion → sistema verifica se bate com algum gatilho
3. Se bater → cria conversa e dispara o funil escolhido automaticamente

Filtro por instância: deixe vazio para aceitar de qualquer instância, ou selecione apenas algumas para o gatilho funcionar só nelas.

⚠️ Importante: o gatilho de início só funciona se o cliente NÃO tem conversa ativa. Se cliente já está em algum funil (PIX, ABANDONO, etc), a mensagem dele é processada como resposta do funil atual.
♻️ Reativação: se cliente tem conversa completada/cancelada há mais de 3 dias, o sistema tenta reativação ANTES do start_trigger. Se não houver funil de reativação configurado, aí sim cai no start_trigger.

Funil de Recuperação (Remarketing 24h)
Dispara um funil novo X horas depois que o cliente completou o funil PIX ou ABANDONO sem pagar. Útil pra oferta de desconto (ex: R$9,99).
🛡️ Proteção tripla: cliente que já pagou alguma vez NUNCA recebe (não queima base) · cliente em outro funil ativo é pulado · cliente na blacklist é pulado.
⚠️ ANTES de ativar: crie os 2 funis na aba "Funis" e configure produto na Kirvano com link próprio (ex: R$9,99 com nome "RECUPERAÇÃO REMARKETING").
